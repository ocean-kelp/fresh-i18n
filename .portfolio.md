# 🌍 Fresh i18n
[![JSR](https://jsr.io/badges/@xiayun/fresh-i18n)](https://jsr.io/@xiayun/fresh-i18n)

The **fastest, cleanest, and most developer-friendly** internationalization (i18n) solution built specifically for the [Fresh](https://fresh.deno.dev) framework for Deno. 

## 🎯 The Problem Solved
Traditional i18n solutions require massive bundled payloads and exhausting "prop-drilling" across server components and client-side islands. **Fresh i18n** completely eliminates this by delivering context directly to your islands without passing down massive dictionaries as props.

## ✨ Core Features
- **Zero-Prop Islands**: Access translations directly inside islands using `useTranslation()`. No more passing `labels={...}` manually through 5 layers of UI.
- **Ultra-Lightweight Engine**: Injects *only* the translations required for the active route. Achieves up to a **90% payload reduction** compared to traditional providers!
- **Namespaced Translators**: Stop typing huge, nested keys like `features.navigator.dashboard.save`. `createNamespacedTranslator()` auto-infers nested properties seamlessly.
- **SEO Native**: Full server-side rendering (SSR) by default for meta tags, transitioning instantly to client-side hydration.
- **Smart Fallbacks**: Completely robust developer experience. Missing keys fail gracefully in production but illuminate clearly during local development.

## 🏗️ Developer Experience
Integrating `Fresh i18n` takes less than 60 seconds:
```typescript
import { i18n } from "@xiayun/fresh-i18n";

app.use(i18n({
  languages: ["en", "es"],
  defaultLanguage: "en",
  localesDir: "./locales"
}));
```
